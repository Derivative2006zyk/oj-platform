### 六、配置路由

#### 1、创建 src/router/index.ts

在 `frontend/src/` 下创建 `router/` 目录，并新建 `index.ts`：

```typescript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: '/',
      name: 'problem-list',
      component: () => import('../views/ProblemList.vue')
    },
    {
      path: '/problem/:id',
      name: 'problem-detail',
      component: () => import('../views/ProblemDetail.vue')
    },
    {
      path: '/admin/problem/new',
      name: 'problem-create',
      component: () => import('../views/ProblemEdit.vue')
    },
    {
      path: '/admin/problem/:id/edit',
      name: 'problem-edit',
      component: () => import('../views/ProblemEdit.vue')
    }
  ]
})

export default router
```

#### 2、路由结构说明

| 路径 | 名称 | 用途 |
|---|---|---|
| `/` | problem-list | 题目列表页 |
| `/problem/:id` | problem-detail | 题目详情页 |
| `/admin/problem/new` | problem-create | 新建题目 |
| `/admin/problem/:id/edit` | problem-edit | 编辑题目 |

`admin` 前缀的路由表示管理员操作，后续可在路由守卫中增加鉴权。

#### 3、动态路由参数

`:id` 是动态参数，可以在组件中通过 `useRoute().params.id` 获取。例如 `/problem/123` 中，`id` 为 `123`。

#### 4、懒加载组件

```typescript
component: () => import('../views/ProblemList.vue')
```

动态导入，首次访问该路由时才加载对应组件，减小首屏体积。

### 八、配置 Vite 代理（可选）

前后端分离时，前端运行在 5173 端口，后端在 8000 端口。为避免跨域，可以在 Vite 中配置代理。

#### 1、修改 vite.config.ts

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true
      }
    }
  }
})
```

#### 2、代理的作用

配置后，前端请求 `/api/problems` 会被 Vite 转发到 `http://localhost:8000/api/problems`，浏览器看不到跨域。

本项目后端已配置 CORS 中间件允许所有源，因此代理是可选的。

### 九、封装 API 客户端

#### 1、创建 src/api/problem.ts

在 `frontend/src/` 下创建 `api/` 目录，并新建 `problem.ts`：

```typescript
import axios from 'axios'

const api = axios.create({
  baseURL: 'http://localhost:8000/api'
})

// ===== 分类 =====
export interface Category {
  id: number
  name: string
  description?: string
  sort_order: number
}

export async function getCategories(): Promise<Category[]> {
  const res = await api.get('/categories')
  return res.data
}

// ===== 题目 =====
export interface ProblemSummary {
  id: number
  title: string
  type: string
  difficulty: number
  tags: string[]
  category_id: number
}

export interface ProblemListResponse {
  total: number
  page: number
  page_size: number
  items: ProblemSummary[]
}

export async function getProblems(params: {
  page?: number
  page_size?: number
  category_id?: number
  difficulty?: number
  type?: string
  tag?: string
  keyword?: string
}): Promise<ProblemListResponse> {
  const res = await api.get('/problems', { params })
  return res.data
}

export async function getAllTags(): Promise<string[]> {
  const res = await api.get('/tags')
  return res.data
}

// ===== 题目详情 =====
export interface TestCase {
  input_data: string
  expected_output: string
}

export interface Subproject {
  id: number
  title: string
  description: string
  hint?: string
  reference_links: { title: string; url: string; note?: string }[]
  answer_guide?: string
  sort_order: number
}

export interface ProblemDetail {
  id: number
  title: string
  description: string
  type: string
  difficulty: number
  tags: string[]
  category_id: number
  explanation?: string
  options?: { key: string; content: string; is_correct: boolean }[]
  blanks?: { blank_index: number; correct_answers: string[]; match_rule: string }[]
  test_cases: TestCase[]
  subprojects: Subproject[]
}

export async function getProblemDetail(id: number): Promise<ProblemDetail> {
  const res = await api.get(`/problems/${id}`)
  return res.data
}

export async function getProblemAnswer(id: number): Promise<{ answer: string; explanation: string }> {
  const res = await api.get(`/problems/${id}/answer`)
  return res.data
}

// ===== 管理 =====
export async function createProblem(data: any): Promise<{ id: number }> {
  const adminKey = localStorage.getItem('admin_key') || ''
  const res = await api.post('/admin/problems', data, {
    headers: { 'X-Admin-Key': adminKey }
  })
  return res.data
}

export async function updateProblem(id: number, data: any): Promise<{ id: number }> {
  const adminKey = localStorage.getItem('admin_key') || ''
  const res = await api.put(`/admin/problems/${id}`, data, {
    headers: { 'X-Admin-Key': adminKey }
  })
  return res.data
}

export async function deleteProblem(id: number): Promise<{ message: string }> {
  const adminKey = localStorage.getItem('admin_key') || ''
  const res = await api.delete(`/admin/problems/${id}`, {
    headers: { 'X-Admin-Key': adminKey }
  })
  return res.data
}

// ===== 图片 =====
export async function uploadImage(file: File, problemId?: number): Promise<{ id: number; url: string }> {
  const adminKey = localStorage.getItem('admin_key') || ''
  const formData = new FormData()
  formData.append('file', file)
  if (problemId) {
    formData.append('problem_id', String(problemId))
  }
  const res = await api.post('/admin/images', formData, {
    headers: {
      'X-Admin-Key': adminKey,
      'Content-Type': 'multipart/form-data'
    }
  })
  return res.data
}
```

#### 2、API 模块的职责

| 分类 | 函数 | 用途 |
|---|---|---|
| 分类 | getCategories | 获取分类列表 |
| 题目 | getProblems | 分页查询题目 |
| 题目 | getAllTags | 获取所有标签 |
| 题目 | getProblemDetail | 获取题目详情 |
| 题目 | getProblemAnswer | 查看答案 |
| 管理 | createProblem | 创建题目 |
| 管理 | updateProblem | 更新题目 |
| 管理 | deleteProblem | 删除题目 |
| 图片 | uploadImage | 上传图片 |

#### 3、管理员密钥的存取

管理接口通过 `localStorage.getItem('admin_key')` 读取密钥，在录入页用户输入后保存到 localStorage。这样避免每次请求时手动输入。

### 十二、注意事项

#### 1、Node.js 版本要求

Vite 5 要求 Node.js 18+。检查方式：`node --version`。若版本过低，先升级 Node.js。

#### 2、npm 安装速度慢

默认源在国外，可临时切换为国内镜像：

```
npm config set registry https://registry.npmmirror.com
```

恢复默认源：

```
npm config set registry https://registry.npmjs.org
```

#### 3、端口冲突

Vite 默认使用 5173 端口。若被占用，Vite 会自动尝试 5174、5175。也可在 `vite.config.ts` 中修改 `server.port`。

#### 4、路由路径必须以 / 开头

vue-router 要求所有 `path` 以 `/` 开头。写成 `'admin/problem/new'` 会报错：

```
Route paths should start with a "/"
```

正确写法：`'/admin/problem/new'`。

#### 5、路由路径的单复数

资源路径用复数：`/problems`。本项目详情页用 `/problem/:id`（单数）是历史约定，与 API 路径 `/api/problems` 不同，注意区分。

#### 6、前后端联调的三个终端

| 终端 | 目录 | 命令 |
|---|---|---|
| 终端1 | 项目根目录 | `docker compose up -d` |
| 终端2 | backend | `uvicorn app.main:app --reload --port 8000` |
| 终端3 | frontend | `npm run dev` |

三个都必须运行，关掉任何一个都会导致相应服务停止。

#### 7、.vue 文件的三个标签

- `<template>`：定义 HTML 结构
- `<script setup lang="ts">`：定义 TypeScript 逻辑
- `<style scoped>`：定义局部样式，scoped 表示只作用于当前组件

#### 8、路由懒加载

`component: () => import(...)` 是动态导入。首次访问该路由时才加载组件代码。首屏只加载当前路由所需代码，性能更好。

#### 9、localStorage 的使用

- `localStorage.setItem('key', value)` 永久保存
- `localStorage.getItem('key')` 读取
- 清除浏览器数据会丢失
- 不要存敏感信息（如密码）

#### 10、axios 的 baseURL

本项目后端地址为 `http://localhost:8000/api`。生产环境应改为相对路径或通过环境变量配置。目前为了开发方便，硬编码在 `api.ts` 中。

#### 11、TypeScript 类型导入

`import type { Category } from ...` 表示仅导入类型，编译后不生成代码。也可直接 `import { Category }`。

#### 12、node_modules 不要提交

`node_modules/` 已在 `.gitignore` 中。若误提交：

```
git rm -r --cached frontend/node_modules
```

#### 14、白屏问题排查顺序

1. 打开 F12 Console 看报错
2. 看 Vite 终端是否有 `Internal server error`

5. 检查路由 `path` 是否以 `/` 开头
6. 检查 `views/` 目录名（不是 `view`）
