### 三、密码哈希

```python
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(plain: str) -> str:
    return pwd_context.hash(plain)

def verify_password(plain: str, hashed: str) -> bool:
    return pwd_context.verify(plain, hashed)
```

### 四、JWT

```python
def create_access_token(user_id, username, role) -> str:
    payload = {"sub": str(user_id), "username": username, "role": role, "exp": expire}
    return jwt.encode(payload, SECRET, algorithm=ALGORITHM)

def decode_access_token(token: str) -> dict | None:
    try:
        return jwt.decode(token, SECRET, algorithms=[ALGORITHM])
    except JWTError:
        return None
```

### 九、踩坑记录

#### 1、`__init__.py` 拼写错

`user_plugin/init.py` 少双下划线，导致 `@register_plugin` 从未执行，`/api/auth/*` 404。Python 只把 `__init__.py` 当作包初始化文件。

#### 2、迁移未执行

`plugin_configs` 迁移文件生成了但没 `alembic upgrade head`，backend 启动报 `relation "plugin_configs" does not exist`。

#### 3、测试连接池跨 loop

`database.py` 在 `TESTING=1` 时用 NullPool，避免连接跨事件循环复用。

#### 4、pytest loop scope 不能设 session

pytest-asyncio 0.24 里，fixture 和测试函数若 loop scope 不一致会报 `got Future attached to a different loop`。保持默认（都 function）。

#### 5、Windows 记事本保存文件

VS Code 保存偶发不落盘（编码或路径问题）。改用：

```
del 文件
notepad 文件
（粘贴 + 保存）
```

用 `findstr` 验证内容已写入。

#### 6、curl 长 token

Windows cmd 对长 `Authorization: Bearer <token>` 处理有缺陷。改用容器内 Python httpx 验证。
