### 七、踩坑记录

#### 1、nullable=False 必须配 server_default

给已有表加非空列，不给默认值会导致所有现有行插入失败。

**修复**：

```python
sa.Column('is_active', sa.Boolean(), nullable=False, server_default=sa.text('true'))
```

#### 2、require_admin 依赖链

```
require_admin → get_current_user → HTTPBearer → JWT → DB
```

任何一层失败返回对应错误。

#### 3、admin_router 与主 router 分开

`user_plugin/api.py` 里有两个 APIRouter，都返回给 `get_routers`。

#### 4、封禁后已发 token 仍有效

JWT 无状态，只做登录校验。彻底禁止需在 `get_current_user` 里查 `is_active`。
