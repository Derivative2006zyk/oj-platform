# 第 47 天：插件市场的在线下载与安装

### 一、今日目标

- 实现 `.ojplugin` 插件包的在线下载、安全解压与校验
- 后端暴露插件前端静态文件服务
- 前端实现 `iframe` 微前端隔离加载插件页面
- 前端设置页新增“插件市场”安装面板
- 解决 Vite 代理跨域请求静态资源的问题

### 二、核心实现

#### 1、后端下载与安全解压
- 新增 `backend/app/plugins/problem_plugin/market_api.py`。
- 接收前端传来的 `download_url`，使用 `httpx` 下载 ZIP 文件。
- 使用 `zipfile` 解压时，加入了防 Zip Slip（路径穿越）攻击的校验逻辑。
- 校验解压后的目录必须包含 `manifest.json`，否则视为无效插件包。
- 将插件移动到 `plugins_installed` 目录。

#### 2、后端静态文件挂载
- 在 `main.py` 中引入 `StaticFiles`。
- 将 `/app/plugins_installed` 目录挂载到 `/plugins_static` 路由。
- 这样外部插件自带的 HTML、CSS、JS 资源就可以直接被浏览器访问。

#### 3、前端微前端（Micro-Frontend）加载
- 修改 `PluginView.vue`。
- 放弃了危险的动态 `import()` 执行远程 JS，改用最安全、最彻底的隔离方案：**`<iframe>`**。
- 通过拼接 `getBackendUrl() + /plugins_static/插件名/frontend/index.html`，让主应用将插件作为独立的沙箱页面嵌入。
- 修改 `vite.config.ts`，增加 `/plugins_static` 的代理，解决开发环境下的跨域请求问题。

#### 4、前端插件市场 UI
- 在 `Settings.vue` 底部新增“插件市场”面板，硬编码了一个 `Hello World` 的演示插件。
- 点击“一键安装”调用后端安装接口，并提示用户重启应用。

### 三、踩坑记录

#### 1、插件页面空白，报 404
**现象**：路由跳转成功，但页面只有“该插件未提供前端页面”。
**原因**：
1. 早期的 `PluginView.vue` 只是一个占位符，没有真正加载外部 HTML。
2. 测试的插件文件夹中漏建了 `frontend/index.html`。
3. Vite 开发服务器没有配置 `/plugins_static` 的代理。
**解决**：补齐 HTML 文件，重写 `PluginView.vue` 使用 iframe，并在 `vite.config.ts` 中配置代理。

#### 2、Docker 容器内无法访问本地文件
**现象**：用 Python 在本地开 HTTP 服务器，后端请求失败。
**原因**：后端运行在 Docker 容器中，`127.0.0.1` 指向的是容器自身。
**解决**：在 Windows/Mac 下，使用 `host.docker.internal` 替代 `127.0.0.1` 来访问宿主机。
