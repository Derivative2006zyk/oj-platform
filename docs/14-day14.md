### 二、Redis 服务接入

#### 1、docker-compose 新增 redis

```yaml
redis:
  image: redis:7-alpine
  command: redis-server --appendonly yes
  ports:
    - "6379:6379"
  volumes:
    - ./data/redis:/data
  healthcheck:
    test: ["CMD", "redis-cli", "ping"]
    interval: 5s
    timeout: 3s
    retries: 5
  restart: unless-stopped
```

#### 2、backend 环境变量

```yaml
REDIS_URL: redis://redis:6379/0
EVENT_BUS_CHANNEL: oj:events
```

#### 3、绑定挂载

项目总览 2.2.2 要求数据卷必须绑定挂载：

- PostgreSQL：`./data/postgres:/var/lib/postgresql/data`
- Redis：`./data/redis:/data`

好处：用户可见、Docker 卸载不影响、项目目录复制即迁移。

#### 3、工厂函数

```python
def get_event_bus() -> EventBus:
    global _event_bus
    if _event_bus is None:
        _event_bus = EventBus(settings.REDIS_URL)
    return _event_bus
```

### 四、FastAPI 集成

使用 lifespan：

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    bus = get_event_bus()
    await bus.connect()
    await bus.start_listening()
    yield
    await bus.disconnect()
```

`/health` 返回：

```json
{"status":"ok","redis":"ok"}
```

### 五、数据迁移

0.1 用命名卷 `pg_data`，0.2 改用绑定挂载 `./data/postgres`。

迁移步骤：

1. `pg_dump` 备份为 `backup_0.1.sql`
2. `docker compose down`（不加 `-v`）
3. 修改 `docker-compose.yml` 为绑定挂载
4. `docker compose up -d postgres redis`
5. `type backup_0.1.sql | docker exec -i ... psql`
6. 验证数据完整
7. 跑 1-2 天后删除旧命名卷

#### 踩坑记录

- 旧命名卷在 `docker compose down` 时被 Compose 当作孤儿卷清理
- 幸好备份文件有效，从 SQL 恢复成功
- 教训：**备份文件的验证一定要在 down 之前做**

### 六、注意事项

#### 1、容器内 Redis 主机名

容器内必须用 `redis`，不是 `localhost`。

#### 2、测试 Redis DB

开发 DB 0，测试 DB 1。

#### 3、绑定挂载

数据必须在项目目录下（`./data/`），不能用命名卷。

#### 4、Redis AOF

必须 `--appendonly yes`，保证 1 秒内的持久化。

#### 5、不要加 -v

`docker compose down -v` 会删卷，迁移期间绝对不要执行。

#### 6、ASGITransport 不触发 lifespan

`client` fixture 必须手动调用 `bus.connect()` 和 `bus.start_listening()`。

### 九、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| ConnectionRefusedError | Redis 未启动 | docker compose up -d redis |
| redis down | 连接失败 | 检查 REDIS_URL |
| 收不到事件 | 频道不一致 | 检查 EVENT_BUS_CHANNEL |
| Event loop is closed | 跨事件循环复用 | 独立 connect/disconnect |
| data/postgres 为空 | 用了命名卷 | 检查挂载配置 |
| pg_dump 输出 0 字节 | 用了 PowerShell | 改用 cmd |
