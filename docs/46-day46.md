# 第 46 天：前端动态菜单与插件管理

### 一、今日目标

- 后端增加接口，读取已安装插件的 `manifest.json` 并返回给前端
- 前端 Pinia 新增 `pluginStore`，管理插件列表状态
- `NavBar.vue` 根据插件列表动态渲染导航菜单
- `router/index.ts` 增加通用的 `/plugin/:name` 占位路由
- `Settings.vue` 增加“已安装插件”管理区域
- 配置 `.gitignore` 忽略运行时外部插件代码

### 二、核心实现

#### 1、后端暴露插件元数据
- 在 `backend/app/core/plugin_registry.py` 中新增 `get_ui_manifests()` 方法，遍历 `/app/plugins_installed` 目录，读取其中的 `manifest.json` 并返回。
- 在 `backend/app/main.py` 中新增公共接口 `GET /api/plugins/ui`，将上述列表暴露给前端。

#### 2、前端状态管理与动态渲染
- 新建 `frontend/src/stores/plugin.ts`，定义 `PluginManifest` 接口，并提供 `fetchPlugins` 方法从后端拉取数据。
- 修改 `frontend/src/components/NavBar.vue`，在 `onMounted` 时调用 `fetchPlugins`，并利用 `v-for` 遍历 `pluginStore.plugins`，动态生成菜单项。
- 修改 `frontend/src/router/index.ts`，新增路由 `/plugin/:name`，指向占位组件 `PluginView.vue`。
- 新建 `frontend/src/views/PluginView.vue`，用于展示动态加载的插件信息。
- 修改 `frontend/src/views/Settings.vue`，新增“已安装的扩展插件”卡片，展示当前安装的插件版本和作者。

#### 3、Git 忽略运行时插件
- 修改根目录 `.gitignore`，忽略 `backend/plugins_installed/*`，但保留 `.gitkeep`，确保仓库干净的同时，Docker 挂载目录不会丢失。

### 三、踩坑记录

#### 1、动态路由组件缺失
**现象**：修改完路由后，前端终端报错 `找不到模块“../views/PluginView.vue”`。
**原因**：在 `router/index.ts` 中写了动态导入，但忘记创建对应的 Vue 组件文件。
**解决**：在 `views` 目录下新建 `PluginView.vue`，并实现基础的接收路由参数与展示逻辑。

#### 2、外部插件代码混入版本库
**现象**：测试完 `hello_world` 插件后，`git status` 提示 `backend/plugins_installed/` 未追踪。
**原因**：插件属于运行时外部资源，不应该提交到主代码仓库。
**解决**：在 `.gitignore` 中忽略里面的具体内容，并在文件夹中放置一个 `.gitkeep` 空文件，确保空目录能被 Git 记录。
