### 二、导出扩展

`POST /api/admin/bank/export` 请求体：

```json
{ "problem_ids": [1,2,3] }
{ "bank_id": 5 }
{}
```

优先级：`problem_ids` > `bank_id` > 全部。

manifest 每道题加 `bank_name`，另有 `banks` 数组。

### 三、导入

`POST /api/admin/bank/import`：

- `file`: ZIP
- `conflict_strategy`: skip / rename / overwrite

流程：

1. 解析 manifest.json，校验 format
2. 扫描所有 `images/xxx.ext` 引用
3. 图片按 sha256 前 16 位命名，落盘到 `uploads/{年}/{月}/`
4. 遍历题目：分类/题库匹配或创建，冲突处理，图片引用替换为 `/api/images/N`
5. 落库 Problem + TestCase + ResearchSubproject
6. 返回统计

### 四、冲突策略

| 策略 | 行为 |
|---|---|
| skip | 标题已存在则跳过 |
| rename | 标题后加 `(导入N)` |
| overwrite | 删除同名旧题后新建 |

### 六、踩坑记录

#### 1、图片目录按年/月存储

现有上传目录是 `uploads/{年}/{月}/`，导出时需要递归查找同名文件。

`_resolve_image_path` 用 `upload_dir.rglob(name)` 兜底。

#### 2、图片去重

导入时按 sha256 前 16 位命名，`images.file_name` 匹配到则复用。
