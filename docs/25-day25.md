### 二、后端新增

#### 1、修改密码

`PUT /api/users/me/password`

```python
async def change_password(db, user, old_password, new_password):
    if not verify_password(old_password, user.hashed_password):
        return False
    user.hashed_password = hash_password(new_password)
    await db.commit()
    return True
```

#### 3、全局替换紫色

原主色 `#4f46e5`（紫）→ `#0066cc`（洛谷蓝）。

替换清单：

| 原内容 | 替换为 |
|---|---|
| `#4f46e5` | `var(--color-primary)` |
| `#4338ca` | `var(--color-primary-hover)` |
| `#a5b4fc` | `var(--color-primary-disabled)` |
| `#7c3aed`（渐变） | `#3399ff` |
| `#eef2ff` / `#eff6ff` | `var(--color-primary-light)` |

用 Python 脚本一次批量替换，避免漏改：

```python
REPLACES = [
    ("linear-gradient(135deg, var(--color-primary), #7c3aed)",
     "linear-gradient(135deg, #0066cc, #3399ff)"),
    ("background: #a5b4fc;", "background: var(--color-primary-disabled);"),
    ("border-color: #4f46e5;", "border-color: var(--color-primary);"),
    ("background: #4f46e5;", "background: var(--color-primary);"),
    ("color: #4f46e5;", "color: var(--color-primary);"),
]
```

### 六、踩坑记录

#### 1、`Optional` 未导入 → 后端重启循环

`judge_plugin/api.py` 用了 `Optional[str]` 但没 `from typing import Optional`。

**现象**：backend 容器 `Restarting (1)`，日志 `NameError: name 'Optional' is not defined`。

**解决**：文件顶部加 `from typing import Optional`。

**教训**：改完后端代码立即看 `docker compose logs backend --tail 20`，确认无 import 错误再继续。

#### 2、NavBar.vue 是 GBK 编码

`findstr` 输出 `鎴戠殑鎻愪氦`（"我的提交"的乱码）。

**解决**：记事本重写，保存时选 UTF-8。

#### 3、`api/user.ts` 未保存导致模块导出缺失

浏览器报 `does not provide an export named 'changePassword'`。

**解决**：记事本重建，验证 `findstr /C:"changePassword"` 有输出。

#### 4、Vite 缓存

改完文件若报旧错误：

```
rmdir /s /q node_modules\.vite
npm run dev
```
