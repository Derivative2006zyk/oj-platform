### 四、Tauri IPC 命令

`main.rs` 加两个命令：

```rust
#[tauri::command]
fn update_tray_tooltip(app: AppHandle, text: String) -> Result<(), String>

#[tauri::command]
fn refresh_tray_from_backend(app: AppHandle, token: String) -> Result<(), String>
```

`refresh_tray_from_backend` 流程：

1. reqwest 拉 `/api/widget/summary`
2. 解析 JSON 到 `WidgetSummary`
3. 构造 tooltip 多行字符串
4. `app.tray_by_id("main").set_tooltip(...)`

注册：

```rust
.invoke_handler(tauri::generate_handler![
    update_tray_tooltip,
    refresh_tray_from_backend,
])
```

托盘必须 `TrayIconBuilder::with_id("main")`，否则 `tray_by_id` 找不到。

### 五、前端集成

#### 1、`utils/tauri.ts`

```typescript
export function isTauri(): boolean {
  return !!(window as any).__TAURI_INTERNALS__
}

export async function refreshTrayFromBackend(token: string) {
  if (!isTauri()) return
  const { invoke } = await import('@tauri-apps/api/core')
  await invoke('refresh_tray_from_backend', { token })
}
```

#### 2、`stores/user.ts`

- login 后调 `refreshTrayFromBackend(token)`
- logout 后调 `updateTrayTooltip('OJ Platform')`

#### 3、`main.ts`

启动时若已登录，延迟 2 秒调 `refreshTrayFromBackend`

#### 4、`ProblemDetail.vue`

WS 收到 judged 后刷新 tooltip。

### 六、踩坑记录

#### 1、asyncpg aware/naive datetime

**错误**：`can't subtract offset-naive and offset-aware datetimes`

**原因**：`created_at` 是 `TIMESTAMP WITHOUT TIME ZONE`（naive），用 `datetime.now(timezone.utc)`（aware）比较。

**修复**：

```python
today_start = datetime.now(timezone.utc).replace(
    tzinfo=None,     # 去时区
    hour=0, minute=0, second=0, microsecond=0,
)
```

#### 2、Tauri 托盘 tooltip 需要 ID

`TrayIconBuilder::new()` 无 id，`tray_by_id("main")` 找不到。

**修复**：`TrayIconBuilder::with_id("main")`。

#### 3、tooltip 不主动刷新

启动时的默认 tooltip 一直保留，前端调 IPC 才更新。

**修复**：前端在关键时机调 `refresh_tray_from_backend`。

#### 4、`__TAURI_INTERNALS__` vs `__TAURI__`

Tauri v2 用 `window.__TAURI_INTERNALS__`。Tauri v1 用 `__TAURI__`。

**检测环境**：`typeof window.__TAURI_INTERNALS__ !== 'undefined'`。
