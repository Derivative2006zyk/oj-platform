### 二、题库导出

#### 2.1 文件格式

ZIP：

```
ojbank_YYYYMMDD_HHMMSS.zip
├── manifest.json
└── images/
    └── {sha256_16}.{ext}
```

manifest.json：

```json
{
  "format": "oj-platform-bank",
  "format_version": 1,
  "created_at": "2026-10-13T15:30:45Z",
  "app_version": "0.2.0",
  "problem_count": 5,
  "image_count": 2,
  "categories": [{"name": "算法", "description": "...", "sort_order": 1}],
  "problems": [...]
}
```

#### 2.2 关键设计

- **不带数据库 ID**：导入时重建
- **分类按名称匹配**：避免 ID 冲突
- **图片用 sha256 前 16 位命名**：天然去重
- **描述中 `/api/images/N` 替换为 `images/{hash}.ext`**：导出时重写，导入时反向替换

#### 2.3 图片路径解析

`_resolve_image_path` 兼容多种存法：

- 绝对路径（宿主机调试）
- `uploads/xxx.png`
- `uploads/images/xxx.png`
- 仅文件名

按顺序尝试，第一个存在的即用。

#### 2.4 导出 API

```
POST /api/admin/bank/export
Header: X-Admin-Key
Body: {"problem_ids": [1,2,3]} 或 {"problem_ids": null}
Response: application/zip
```

### 三、题库（Bank）数据模型

新增 `banks` 表：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| name | String(100) | 唯一 |
| description | Text | 可空 |
| sort_order | Integer | 默认 0 |
| created_at | DateTime | server_default |

`problems.bank_id`：外键，可空，`ondelete=SET NULL`。

**删除题库**：该题库下题目的 `bank_id` 置空，题目保留。

### 四、题库 CRUD API

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/banks` | 公开，带 problem_count |

| PUT | `/api/admin/banks/{id}` | 管理员 |
| DELETE | `/api/admin/banks/{id}` | 管理员 |

### 七、踩坑记录

#### 1、`bank.py` 内容缺失

**现象**：`ImportError: cannot import name 'Bank' from 'app.models.bank'`。

**原因**：`bank.py` 文件创建了但内容没写或写错。

**解决**：确认文件里有 `class Bank(Base)`。

#### 2、Alembic 未识别新模型

**现象**：`alembic revision --autogenerate` 报 `cannot import name 'Bank'`。

**原因**：`alembic/env.py` 只 import 了旧模型，没 import `Bank`，导致模型未注册。

**解决**：在 `env.py` 里补 `from app.models import ..., Bank, ...`。

#### 3、`_infer_submission_kind` 重复

Day 37 遗留：`schemas/submission.py` 和 `service.py` 各有一份 `_infer_submission_kind`，改动必须两处同步。0.3 可合并。

#### 4、`page_size` 上限

原上限 50，前端分组视图需要一次拉全部匹配题目，改为 200。数据量再大时应考虑分页拉取 + 前端聚合。

### 十、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `ImportError: Bank` | bank.py 内容缺失 | 补全 Bank 类 |
| Alembic 不识别 Bank | env.py 未 import | 在 env.py 加 Bank |
| 导出 ZIP 无图片 | 图片路径解析失败 | 检查 `settings.UPLOAD_DIR` 与 file_path |
| 分组视图题目不全 | page_size 限制 | 提高到 200 或按分组分别拉取 |
| 前端无题库下拉 | `listBanks` 调用失败 | 检查 `/api/banks` 是否可用 |
