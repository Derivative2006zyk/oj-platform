### 二、核心实现

#### 1、一键备份与恢复
- **后端实现**：在 `Dockerfile` 中安装 `postgresql-client`。新增 `backup_api.py`。
  - `GET /api/admin/backup/export`：调用系统 `pg_dump` 导出数据库，连同 `uploads` 图片文件夹，打包成 ZIP 下载。
  - `POST /api/admin/backup/import`：解压 ZIP，先清空 Schema，再执行 SQL 导入数据，最后复制图片。
- **前端实现**：在 `Settings.vue` 增加数据管理卡片，支持下载备份文件和上传备份恢复，带二次确认弹窗。

#### 2、补充题目管理功能
- **后端**：在 `ProblemPlugin` 的路由注册中，补上了 `backup_router`，修复了备份接口 404 的问题。
- **前端**：在 `ProblemList.vue` 的题目卡片右侧增加操作区。当 `userStore.isAdmin` 时，显示“编辑”和“删除”按钮，点击时阻止事件冒泡，防止触发跳转详情页。

### 三、踩坑记录

#### 1、Docker build 时 apt-get 卡死
**现象**：执行 `docker compose build backend` 时，在 `apt-get update` 阶段卡住近 10 分钟甚至超时。
**原因**：官方 `python:3.11-slim` 镜像默认访问海外 Debian 源 `deb.debian.org`，国内网络极慢。
**解决**：在 `Dockerfile` 运行 `apt-get` 前，先使用 `sed` 命令将源替换为清华镜像源 `mirrors.tuna.tsinghua.edu.cn`，实现秒级更新。

#### 2、备份接口报 404 Not Found
**现象**：点击导出备份时报错 `Request failed with status code 404`。
**原因**：新建了 `backup_api.py` 并写好了路由，但忘记在 `problem_plugin/__init__.py` 的 `get_routers` 中返回它。
**解决**：在 `get_routers` 的返回列表中加入 `backup_router`。
