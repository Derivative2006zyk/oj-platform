### 三、CodeEditor 组件

#### 1、Props / Events

| Prop | 类型 | 默认 |
|---|---|---|
| `modelValue` | `string` | - |
| `language` | `string` | `python` |
| `height` | `string` | `360px` |
| `readonly` | `boolean` | `false` |

Emit：`update:modelValue`

#### 2、核心逻辑

```typescript
editor = monaco.editor.create(containerRef.value, {
  value: props.modelValue,
  language: normalizeLanguage(props.language),
  theme: 'vs',
  automaticLayout: false,
  ...
})

editor.onDidChangeModelContent(() => {
  emit('update:modelValue', editor!.getValue())
})

resizeObserver = new ResizeObserver(() => editor?.layout())
resizeObserver.observe(containerRef.value)
```

卸载：

```typescript
onBeforeUnmount(() => {
  resizeObserver?.unobserve(containerRef.value)
  editor?.dispose()
})
```

#### 3、按需加载语言

```typescript
import * as monaco from 'monaco-editor/esm/vs/editor/editor.api'

import 'monaco-editor/esm/vs/basic-languages/python/python.contribution'
import 'monaco-editor/esm/vs/basic-languages/java/java.contribution'
import 'monaco-editor/esm/vs/basic-languages/cpp/cpp.contribution'

import EditorWorker from 'monaco-editor/esm/vs/editor/editor.worker?worker'
```

**不加载**全部语言，只加载这三种，bundle 减少约 300-500 KB。

### 六、性能优化清单

| 优化 | 效果 |
|---|---|
| 按需加载语言 | bundle 减少 ~400 KB |
| 关闭 occurrencesHighlight | 输入更流畅 |
| 关闭 codeLens / folding / hover | 渲染更轻 |
| 关闭 quickSuggestions | 不弹提示框 |
| 关闭 matchBrackets / renderIndentGuides | 无额外 DOM |
| `defineAsyncComponent` | 首屏不阻塞 |
| `optimizeDeps.include` | Vite 预构建 |

保留的功能：语法高亮、行号、自动缩进、Tab、光标、拖动缩放。

### 七、踩坑记录

#### 1、monaco-editor 装到根目录

在 `oj-platform/` 跑 `npm install monaco-editor` 而不是 `oj-platform/frontend/`。

**现象**：根目录多出 `node_modules`、`package.json`、`package-lock.json`。

**解决**：删掉根目录的 npm 产物，在 `frontend/` 重新安装。

#### 2、monaco 0.57 的 worker 路径变更

```
Failed to resolve import "monaco-editor/esm/vs/editor/editor.worker?worker"
```

0.57 的 worker 入口改为 `editor.worker.start.js`，旧路径不可用。

**解决**：降级到 0.52.2（稳定版）。

```
npm uninstall monaco-editor
npm install monaco-editor@0.52.2
```

#### 3、renderIndentGuides 弃用

TS 报错：`“renderIndentGuides”不在类型“IStandaloneEditorConstructionOptions”中`。

**原因**：0.52 移除了这个选项。

**解决**：删掉该行（或用新写法 `guides: { indentation: false }`）。

#### 4、manualChunks 类型不兼容

TS 报错：`“monaco”不在类型“ManualChunksFunction”中`。

**原因**：Rollup 收紧类型，对象形式不再被接受。

**解决**：改成函数形式，或直接删掉 `build` 配置（dev 环境无影响）。

#### 5、编辑器的拖动缩放

Monaco **没有内建** resize handle。

**解决**：外层容器加 `resize: both; overflow: auto`，编辑器 `height: 100%` 撑满外层。

**关键**：`overflow: hidden` 和 `resize` 冲突，**必须**改为 `overflow: auto`。

#### 6、首屏卡顿

默认配置下 Monaco 加载全部语言 + 全部功能，首屏 3-5 秒。

**解决**：按需加载 + 关掉非必要功能 + 异步组件。首屏降到 1-2 秒。
