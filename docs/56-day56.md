# 第 56 天：插件市场 UI 升级与状态区分

### 一、今日目标
- 提升插件市场的视觉体验，将垂直列表升级为现代网格式布局。
- 区分插件状态（未安装、已安装、未上线），避免用户重复安装引发 409 冲突。
- 采用纯 CSS 绘制动态首字母头像作为图标，确保跨平台渲染一致性。

### 二、核心实现

#### 1、后端数据结构扩展
在 `market_api.py` 的 `get_market_plugins` 中，为返回的 JSON 增加了 `category` 字段，并预置了未来要做的「暗色主题」和「AI 助手」的占位数据。

#### 2、前端网格化与状态逻辑
- **网格布局**：在 `Settings.vue` 中使用 `grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))` 实现响应式网格布局。
- **安装状态判断**：新增 `isInstalled(pluginName)` 方法，利用 `pluginStore.plugins` 判断当前市场的插件是否已经在本地安装。
- **按钮动态渲染**：如果未安装且有下载链接，显示“一键安装”；如果已安装，显示灰色不可点击的“已安装”；如果没有下载链接，显示“敬请期待”。

#### 3、纯色首字母头像
- 采用纯 CSS 绘制 UI 图标：提取插件 `display_name` 的第一个字符（如“数学”取“数”），生成对应的圆角背景块。
- 通过哈希算法 `getIconColor(name)` 从固定色板中为每个插件动态分配不同的背景色，保证了 UI 的现代感和辨识度，且在任何环境下表现完全一致。
