### 四、关闭窗口隐藏

```rust
window.on_window_event(move |event| {
    if let WindowEvent::CloseRequested { api, .. } = event {
        api.prevent_close();
        let _ = window_clone.hide();
    }
});
```

### 五、辅助函数

```rust
fn show_main_window(app: &AppHandle) {
    if let Some(w) = app.get_webview_window("main") {
        let _ = w.unminimize();
        let _ = w.show();
        let _ = w.set_focus();
    }
}

fn navigate_to(app: &AppHandle, path: &str) {
    if let Some(w) = app.get_webview_window("main") {
        let _ = w.unminimize();
        let _ = w.show();
        let _ = w.set_focus();
        let js = format!("window.location.href = '{}';", path);
        let _ = w.eval(&js);
    }
}
```

### 八、踩坑记录

#### 1、菜单跳转 pushState 无效

`window.history.pushState` 不触发 Vue Router 的 `popstate` 监听，URL 变了但视图不变。

**修复**：改用 `window.location.href = '/submissions'`，整页刷新，Vue Router 从新 URL 重新初始化。

**代价**：状态丢失，但托盘菜单是低频操作，可接受。

#### 2、最小化后托盘无响应

`w.is_visible()` 在窗口最小化时仍返回 `true`，代码走 `hide()` 分支，用户看不到反应。

**修复**：判断两个状态——

```rust
let visible = w.is_visible().unwrap_or(false);
let minimized = w.is_minimized().unwrap_or(false);

if !visible || minimized {
    // 恢复：unminimize + show + set_focus
} else {
    // 隐藏：hide
}
```

#### 3、capabilities 权限缺失

`unminimize`、`is-minimized` 需要显式声明。

#### 4、default_window_icon 为 None

`tauri.conf.json` 的 `bundle.icon` 不能为空数组，且 `src-tauri/icons/` 下要有对应文件。
