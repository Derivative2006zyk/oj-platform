### 四、后端修复

#### 1、SubmissionSummary 加 runtime_ms

原 schema 只含：

```
id / problem_id / language / status / passed_cases / total_cases / created_at
```

缺 `runtime_ms`，列表接口没返回这个字段。

**修复**：

```python
class SubmissionSummary(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    problem_id: int
    language: str
    status: str
    passed_cases: int
    total_cases: int
    runtime_ms: Optional[int] = None
    created_at: datetime
```

#### 2、前端判断用 `!= null`

原来的 `!== null` 无法排除 `undefined`，导致 `undefined + ' ms'` 变成 `"undefined ms"`。

**修复**：

```typescript
{{ item.runtime_ms != null ? item.runtime_ms + ' ms' : '—' }}
```

### 七、踩坑记录

#### 1、SubmissionSummary 缺 runtime_ms

后端 list 接口不返回该字段，前端拿 `undefined`。

**修复**：schema 加 `runtime_ms: Optional[int] = None`。

#### 2、`!== null` 不排除 undefined

JS 的 `!==` 是严格比较，`undefined !== null` 为 `true`。

**修复**：用 `!= null`（loose）同时排除两者。

#### 3、历史卡片布局丑

初版用 5 列 grid，像数据表格，与洛谷风格不符。

**修复**：改成 flex 行式卡片，浅灰底 + 圆角 + hover 淡蓝。
