### 五、前端 WS 客户端

```typescript
export function openSubmissionWS(submissionId, onMessage): SubmissionWSHandle {
  const token = localStorage.getItem('oj_token')
  const proto = location.protocol === 'https:' ? 'wss:' : 'ws:'
  const url = `${proto}//${location.host}/api/submissions/${submissionId}/ws?token=${encodeURIComponent(token)}`
  const ws = new WebSocket(url)
  ws.onmessage = (e) => onMessage(JSON.parse(e.data))
  return { close: () => ws.close(), isOpen: () => ws.readyState === WebSocket.OPEN }
}
```

### 七、注意事项

#### 1、WS 不支持自定义 header

token 走 query param。

#### 2、Nginx 也要支持 WS

生产环境加 Upgrade/Connection header。

#### 3、WS 端点用独立 session

不用 Depends(get_db)。

#### 4、单例是进程内的

多进程部署需 Redis Pub/Sub 广播（0.3）。

#### 5、关闭码 4001/4004

应用层自定义。

#### 6、onUnmounted 关闭 WS

避免泄漏。
