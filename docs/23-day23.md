### 二、镜像

```dockerfile
FROM gcc:13-slim
WORKDIR /workspace
CMD ["sh", "-c", "g++ -O2 -o /workspace/main /workspace/main.cpp && /workspace/main"]
```

约 1.2 GB。

### 三、C++ 判题

**编译**：

```
docker run --rm --read-only -v <tmpdir>:/workspace:rw \
  judge-cpp:latest g++ -O2 -std=c++17 -o main main.cpp
```

**运行**：

```
docker run --rm -i --read-only -v <tmpdir>:/workspace:ro \
  judge-cpp:latest ./main
```

### 四、worker 分派

```python
if sub.language == "python":
    verdict = judge_python(sub.code, cases)
elif sub.language == "java":
    verdict = judge_java(sub.code, cases)
elif sub.language in ("cpp", "c++", "cpp17"):
    verdict = judge_cpp(sub.code, cases)
```

### 五、注意事项

#### 1、gcc:13-slim 1.2GB

#### 2、编译选项

`-O2 -std=c++17`。

#### 3、段错误退出码 139

#### 4、语言别名

支持 `cpp` / `c++` / `cpp17`。
