### 三、Capacitor 集成

安装依赖：

```bash
cd frontend
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/preferences
```

初始化与添加平台：

```bash
npx cap init "OJ Platform" "com.ojplatform.app" --web-dir=dist
npx cap add android
```

`capacitor.config.ts` 内容：

```ts
import { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'com.ojplatform.app',
  appName: 'OJ Platform',
  webDir: 'dist',
  server: {
    androidScheme: 'https',
  },
};

export default config;
```

开发联调阶段临时启用：

```ts
server: {
  url: 'http://localhost:5173',
  cleartext: true,
},
```

配合 `adb reverse tcp:5173 tcp:5173` 与 `adb reverse tcp:8000 tcp:8000`。提交前必须改回。

### 四、Gradle Wrapper 升级

`frontend/android/gradle/wrapper/gradle-wrapper.properties`：

```properties
distributionUrl=https\://services.gradle.org/distributions/gradle-9.1.0-bin.zip
```

不升级会出现 `Unsupported class file major version`，JDK 25 无法驱动低版本 Gradle。

### 五、前端 token 同步

新建 `frontend/src/utils/native.ts`，封装：

- `syncTokenToNative(token)`
- `clearTokenFromNative()`
- `syncTokenFromLocalStorage()`

修改点：

- `stores/user.ts`：登录后 `syncTokenToNative`，登出后 `clearTokenFromNative`
- `main.ts`：启动时 `syncTokenFromLocalStorage()`

`@capacitor/preferences` 在 Android 端写入 SharedPreferences 文件 `CapacitorStorage`，键 `oj_token`。

### 六、Kotlin App Widget

新增文件：

```text
frontend/android/app/src/main/java/com/ojplatform/app/widget/WidgetData.kt
frontend/android/app/src/main/java/com/ojplatform/app/widget/OjWidgetProvider.kt
frontend/android/app/src/main/java/com/ojplatform/app/widget/OjWidgetWorker.kt
frontend/android/app/src/main/res/layout/widget_oj.xml
frontend/android/app/src/main/res/xml/oj_widget_info.xml
```

`OjWidgetProvider.onUpdate`：

- 立即执行 `OneTimeWorkRequest`
- 注册唯一周期任务 `oj_widget_refresh`，周期 15 分钟

`OjWidgetWorker.doWork`：

- 读 SharedPreferences 中的 `oj_token`
- 无 token：显示“未登录”
- 有 token：OkHttp 请求 `/api/widget/summary`，解析 JSON，更新 RemoteViews
- 请求失败：显示“数据获取失败”或“网络异常”

`widget_oj.xml`：四行文本，标题、今日提交、通过率、已解 / 总题数。

### 七、Android 工程配置

`AndroidManifest.xml`：

- 加 `<uses-permission android:name="android.permission.INTERNET" />`
- `<application>` 加 `android:usesCleartextTraffic="true"`（开发阶段）
- 注册 `.widget.OjWidgetProvider`，`android:exported="true"`

`app/build.gradle`：

```gradle
implementation "androidx.work:work-runtime-ktx:2.9.0"
implementation "com.squareup.okhttp3:okhttp:4.12.0"
```

`strings.xml`：

```xml
<string name="oj_api_base_url">http://10.0.2.2:8000</string>
```

模拟器用 `10.0.2.2`，真机用开发机局域网 IP。

### 八、联调方案

局域网互访不通时，改用 `adb reverse`：

```bash
adb reverse tcp:5173 tcp:5173
adb reverse tcp:8000 tcp:8000
adb reverse --list
```

`capacitor.config.ts` 的 `server.url` 改为 `http://localhost:5173`，App 内 WebView 通过 USB 反转到开发机。

注意：WebView 的 origin 从 `https://localhost` 变为 `http://localhost:5173`，`localStorage` 中的 `oj_token` 会读不到，需要在 App 内重新登录一次。

### 十、踩坑记录

#### 1、JDK 25 与 Gradle

**现象**：Gradle 启动即失败，报 `Unsupported class file major version 69`。

**原因**：Gradle 低于 9.1.0 不支持 Java 25。

**解决**：升级 Gradle Wrapper 到 9.1.0。

#### 2、SDK location not found

**现象**：`SDK location not found. Define a valid SDK location with an ANDROID_HOME`。

**原因**：命令行环境没有 `ANDROID_HOME`。

**解决**：在 `frontend/android/local.properties` 写 `sdk.dir=...`，或在系统环境变量设置 `ANDROID_HOME`。

#### 3、手机访问不了开发机

**现象**：手机浏览器打不开 `http://10.112.197.253:5173/`。

**原因**：WiFi 的 AP 隔离或防火墙拦截。

**解决**：改用 `adb reverse` 端口转发，`server.url` 指向 `http://localhost:5173`。

#### 4、ProblemList 白屏

**现象**：App 内切换页面后内容区一闪即白，Console 报 `Cannot read properties of undefined (reading 'length')`。

**原因**：请求失败时 `data.items` 是 `undefined`，赋给 `problems.value` 后渲染崩溃。

**解决**：`problems.value = Array.isArray(data?.items) ? data.items : []`。

#### 5、AdminUsers 移动端溢出

**现象**：手机上表格横向溢出，角色徽章竖排。

**原因**：表格在窄屏宽度不够。

**解决**：768px 以下切换为卡片布局，徽章加 `white-space: nowrap`。

#### 6、TypeScript 严格模式报未使用变量

**现象**：`vue-tsc -b` 报 `TS6133: 'from' is declared but its value is never read`。

**解决**：改名为 `_from`，或删除未使用的 import。

### 十三、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 小组件显示“未登录” | SharedPreferences 无 token | 打开 App 登录，检查 `CapacitorStorage.xml` |
| 小组件显示“网络异常” | 手机访问不到后端 | 模拟器用 `10.0.2.2`；真机用 `adb reverse` |
| `adb devices` 空 | USB 调试未开或驱动缺失 | 开发者选项开 USB 调试，换数据线 |
| `adb reverse` 无效果 | 拔插 USB 后失效 | 重新执行 `adb reverse` |
| 手机 `localhost:5173` 打不开 | 未执行 adb reverse | `adb reverse tcp:5173 tcp:5173` |
| 切换页面白屏 | 数据未做防御 | 使用 `Array.isArray` 与可选链 |
