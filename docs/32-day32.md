# 第 32 天：Tauri 桌面端自动拉起本地后端

### 一、今日目标

- Rust 检查后端 health
- 未启动则执行 `docker compose up -d`
- 轮询等待就绪（最多 60 秒）
- 失败弹对话框

### 二、启动时序

```
启动 Tauri
  ↓
GET http://localhost:8000/health
  ↓
├── 200 → 加载前端
└── 无响应 → docker compose up -d
              ↓
           轮询 health
              ↓
           ├── 就绪 → 加载
           └── 60s 超时 → 错误对话框 → 退出
```

### 四、核心模块

`backend_launcher.rs`：

```rust
pub fn ensure_backend_ready() -> Result<(), String> {
    if is_backend_running() {
        return Ok(());
    }
    start_backend_stack()?;
    if wait_for_backend() {
        Ok(())
    } else {
        Err("Backend did not become ready".into())
    }
}
```

- `is_backend_running()`：reqwest blocking GET
- `start_backend_stack()`：`Command::new("docker")` 执行
- `wait_for_backend()`：循环检查，1 秒 1 次，最多 60 秒

### 五、main.rs

```rust
fn main() {
    if let Err(err) = ensure_backend_ready() {
        // 弹错误对话框，退出
        ...
        return;
    }
    // 正常启动
    tauri::Builder::default()...
}
```

### 七、踩坑记录

#### 1、首次编译慢

加 reqwest 重新编译依赖树，3-5 分钟。

#### 2、Docker Desktop 必须运行

未运行时 `docker compose up -d` 会失败，错误对话框提示。

#### 3、主线程阻塞

`ensure_backend_ready()` 同步执行，首次启动 10-30 秒无窗口。

**后续优化**：先弹"启动中"窗口，后台线程处理。

#### 4、项目路径硬编码

0.2 假设固定路径，0.3 打包资源目录。
