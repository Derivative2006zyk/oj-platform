### 二、镜像

```dockerfile
FROM openjdk:17-slim
WORKDIR /workspace
CMD ["sh", "-c", "javac /workspace/Main.java && java -cp /workspace Main"]
```

### 三、Java 判题特殊性

- 两步执行：javac 编译 + java 运行
- 类名必须 `Main`，文件必须 `Main.java`
- 编译产物 `.class` 需写到可写目录

### 四、两次 docker run

**编译**：

```
docker run --rm --read-only --network none \
  -v <tmpdir>:/workspace:rw \
  judge-java:latest javac Main.java
```

**运行**：

```
docker run --rm -i --read-only --network none \
  -v <tmpdir>:/workspace:ro \
  judge-java:latest java -cp /workspace Main
```

关键：`/workspace` 编译阶段可写，运行阶段只读。

### 五、CE 与 RE 区分

- javac 返回非 0 → CE
- java 返回非 0 → RE
- java 退出码 137 → MLE
- 超时 → TLE

### 六、注意事项

#### 1、类名必须 Main

#### 2、编译和运行共享 tmpdir

#### 3、`--read-only` 不影响 rw 挂载

#### 4、每个测试点重新编译（今日简化）

#### 5、JVM 本身占内存

#### 6、openjdk 镜像 250MB
