# 第 40 天：Tauri 打包 .msi

### 一、今日目标

- 打包 Windows .msi / .exe 安装包
- 后端资源嵌入 app
- 首次启动自动解压到 `%APPDATA%\oj-platform\`
- 自动拉起 Docker Compose
- 容器启动时自动跑数据库迁移
- 前端适配 Tauri 打包环境（绝对 URL）
- 安装与持久化验证

### 二、方案

- `include_dir!` 编译时嵌入资源
- `prep-assets.js` 把项目根资源拷到 `src-tauri/assets/`
- 首次启动解压到 `%APPDATA%\oj-platform\`
- 从该目录执行 `docker compose up -d`
- 数据在 `%APPDATA%\oj-platform\data\` 持久化
- 后端容器 `entrypoint.sh` 先 `alembic upgrade head` 再启动 uvicorn
- 前端使用绝对 URL `http://127.0.0.1:8000/api`，绕开 Tauri webview origin 问题
- 后端就绪检测用 TCP 探测 `127.0.0.1:8000`，绕开 HTTP/DNS/代理问题

### 六、踩坑记录

#### 1、beforeBuildCommand 的 cwd

**现象**：`系统找不到指定的路径`。

**原因**：`beforeBuildCommand` 的 cwd 是 `desktop/`，不是 `desktop/src-tauri/`。

**解决**：`cd ../frontend`（不是 `../../frontend`）。

#### 2、WiX 首次下载超时

**现象**：`failed to bundle project: timeout: global`。

**原因**：Tauri 从 GitHub 下载 WiX Toolset 超时。

**解决**：手动下载 `wix314-binaries.zip`，解压到 `%LOCALAPPDATA%\tauri\WixTools314\`。NSIS 同理，放到 `%LOCALAPPDATA%\tauri\NSIS\`。

#### 3、后端就绪检查一直失败（核心坑）

**现象**：容器在跑、`curl http://localhost:8000/health` 正常，但 App 报"后端未在 120 秒内就绪"。

**原因**：

- reqwest 默认走系统代理（Clash、v2ray 等），`localhost` 请求被代理拦截。
- 且 reqwest 在 Windows 上可能优先 IPv6 解析 `localhost` 到 `::1`，而 uvicorn 监听 IPv4。

**解决**：

1. 放弃 HTTP 健康检查，改用 TCP 探测：`TcpStream::connect_timeout` 到 `127.0.0.1:8000`。
2. `refresh_tray_from_backend` 里 reqwest client 加 `.no_proxy()`，URL 改 `127.0.0.1`。

#### 4、tauri dev 需要前端 dev server

`beforeDevCommand` 为空，`tauri dev` 会等 `http://localhost:5173`。需另开终端跑 `npm run dev`。

#### 5、打包版所有 API 请求失败

**现象**：Tauri 打包后打开 App，点"录入题目"报"无法连接到服务器"。

**原因**：Tauri webview origin 是 `http://tauri.localhost`，前端用相对路径 `/api/...` 被解析为 `http://tauri.localhost/api/...`，打到 webview 自己，不是后端。Dev 模式能用是因为 Vite 代理。

**解决**：`axios.ts` 和 `ws.ts` 的 URL 改为绝对 `http://127.0.0.1:8000/...`。

#### 6、图片在打包版不显示

**原因**：Markdown 中 `![x](/api/images/N)` 被解析为 `http://tauri.localhost/api/images/N`。

**解决**：`MarkdownRenderer.vue` 渲染前把 `/api/` 前缀替换为 `http://127.0.0.1:8000/api/`。

#### 7、首次启动后端崩溃：relation does not exist

**现象**：全新 `%APPDATA%\oj-platform\data\postgres\` 是空库，后端启动时 `plugin_configs` 表不存在，容器 Exiting。

**原因**：容器启动只跑 uvicorn，不跑迁移。

**解决**：新增 `backend/entrypoint.sh`，先 `alembic upgrade head` 再启动 uvicorn。Dockerfile 改 `ENTRYPOINT`。

#### 8、localStorage 按 origin 隔离

浏览器 `localhost:5173`、Tauri dev `localhost:5173`、Tauri 打包 `tauri.localhost` 三者 localStorage 独立。换环境后需重新登录，token 不共享。
