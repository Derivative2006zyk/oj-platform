### 五、路由守卫

```typescript
const userRaw = localStorage.getItem('oj_user')
const u = JSON.parse(userRaw || '{}')
const isAdmin = u?.role === 'admin'

if (to.meta.requiresAdmin && !isAdmin) {
  next('/')
  return
}
```

### 六、三层权限

1. NavBar：`v-if="userStore.isAdmin"`

3. 后端：`require_admin`

### 七、踩坑记录

#### 1、自己那行禁用操作

`:disabled="u.id === currentUserId"`。

#### 2、`filters.isActive` 类型

`'' as '' | boolean`，允许"全部/正常/封禁"三态。

#### 3、解析 localStorage 要 try/catch

JSON 可能损坏。

#### 4、`Object.assign(u, updated)`

直接合并后端返回的更新后对象。
