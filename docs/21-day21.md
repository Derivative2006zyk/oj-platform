```dockerfile
WORKDIR /workspace
CMD ["python", "/workspace/main.py"]
```

```
docker build -t judge-python:latest ./sandbox/python
```

### 三、沙箱命令（项目总览 12.1）

```
docker run --rm -i \
  --read-only \
  --network none \
  --memory=256m \
  --cpus=1 \
  --pids-limit=64 \
  --security-opt no-new-privileges \
  -v <code_file>:/workspace/main.py:ro \
  judge-python:latest \
  python /workspace/main.py
```

### 四、路径转换

Windows `E:/...` → Docker `/e/...`：

```python
def _to_docker_path(p):
    s = p.resolve().as_posix()
    if s[1] == ":":
        s = f"/{s[0].lower()}{s[2:]}"
    return s
```

### 五、判题流程

1. `py_compile` 检查语法 → CE
2. 逐个测试点执行
3. 状态分类：
   - `exit_code == 137` → MLE
   - `TimeoutExpired` → TLE
   - `exit_code != 0` → RE
   - 输出不匹配 → WA
   - 全通过 → AC
4. 聚合 passed / total / max_runtime

### 六、输出比对

```python
def _normalize_output(s):
    lines = s.replace("\r\n", "\n").split("\n")
    lines = [line.rstrip() for line in lines]
    while lines and lines[-1] == "":
        lines.pop()
    return "\n".join(lines)
```
