# 第 44 天：CI/CD 自动化与 0.2 发布

### 一、今日目标
- 编写 GitHub Actions，实现三平台矩阵构建
- 推送 v0.2.0 Tag，发布安装包
- 更新 README 与项目提示词

### 二、CI/CD 配置
- `build.yml`：监听 main 分支 push，验证前端构建。
- `release.yml`：监听 `v*.*.*` tag，利用 `tauri-apps/tauri-action` 在 Windows、macOS、Ubuntu 上并行构建。
- macOS 配置了 `universal-apple-darwin` 交叉编译，同时支持 Intel 和 M 芯片。

### 三、发布流程
1. 提交工作流文件。
2. 打 Tag `git tag -a v0.2.0 -m "Release 0.2.0"` 并推送。
3. GitHub Actions 自动生成草稿 Release。
4. 检查产物无误后，手动 Publish。

### 四、项目文档更新
- README 增加下载徽章。
- 提示词更新至 v0.4，记录 Docker 沙箱、Tauri 启动器、动态网络等重大架构变动。
