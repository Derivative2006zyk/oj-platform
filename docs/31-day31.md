# 第 31 天：Tauri 桌面端初始化

### 一、今日目标

- 安装 Rust 工具链
- 安装 Tauri CLI
- 创建 desktop/ 项目
- 集成模式加载 frontend dist
- 验证窗口显示前端页面

### 二、安装 Rust

下载 rustup-init.exe，默认安装。

需要 MSVC 工具链（Visual Studio Build Tools，勾选 C++）。

验证：

```
rustc --version
cargo --version
```

### 三、Tauri 项目结构

```
desktop/
├── package.json
└── src-tauri/
    ├── Cargo.toml
    ├── build.rs
    ├── tauri.conf.json
    ├── icons/
    └── src/
        └── main.rs
```

### 四、集成模式配置

`tauri.conf.json`：

```json
{
  "build": {
    "frontendDist": "../frontend/dist",
    "devUrl": "http://localhost:5173",
    "beforeBuildCommand": "cd ../frontend && npm run build"
  },
  "app": {
    "windows": [
      {
        "title": "OJ Platform",
        "width": 1200,
        "height": 800
      }
    ]
  }
}
```

**关键**：

- dev 模式加载 Vite dev server（`http://localhost:5173`）
- build 模式加载前端 dist（`../frontend/dist`）

### 五、启动流程

1. `cd frontend && npm run dev`（保持运行）
2. `cd desktop && npx tauri dev`（另开终端）
3. Tauri 编译 Rust → 弹窗加载前端

### 六、首次编译慢

Rust 首次编译 3-10 分钟。后续增量 10-30 秒。

### 七、踩坑记录

#### 1、cargo not found

rustup 装完没重启终端。关掉重开。

#### 2、WebView2 缺失

Win10/11 一般自带。若没有，下载安装 WebView2 Runtime。

#### 3、link.exe not found

缺 MSVC 工具链。装 Visual Studio Build Tools。

#### 4、窗口白屏

前端 dev server 没跑。检查 `npm run dev`。

#### 5、图标缺失

`tauri build` 报图标缺失。用 `npx tauri icon xxx.png` 生成。
