# 第 42 天：跨平台兼容与多端联调

### 一、今日目标

- 实现前端动态配置后端地址
- 提供桌面端局域网 IP 查询能力
- 首个注册用户默认获得管理员权限
- 移动端连接桌面端后端进行判题测试
- 实现移动端双指缩放与横屏代码模式
- 实现无 Docker 的纯客户端模式运行

### 二、动态网络配置与免登录设置

1. **统一网络入口**：前端 `axios.ts` 和 `ws.ts` 不再写死 `127.0.0.1:8000`，而是统一从 `backend-url.ts` 获取。支持浏览器、桌面端、移动端动态切换。
2. **设置页面**：新增 `Settings.vue`，用户可以输入局域网 IP（如 `http://192.168.1.100:8000`），测试连接并保存到 `localStorage`。
3. **免登录拦截**：修复了“必须先登录才能配置 IP，但没 IP 无法登录”的死循环。将 `/settings` 路由放开限制，并在 `NavBar.vue` 未登录状态也显示“设置”按钮。

### 三、首个用户管理员

修改 `backend/app/plugins/user_plugin/service.py` 的 `create_user`。
在创建用户前，查询 `users` 表的总数（`select(func.count()).select_from(User)`）。
如果为 0，则当前注册用户的 `role` 赋值为 `"admin"`，否则为 `"user"`。

### 四、纯客户端模式与局域网联调

1. **Tauri 纯客户端**：修改 `desktop/src-tauri/src/main.rs`，当 `ensure_backend_ready()` 启动本地 Docker 失败时，弹窗提示用户是否作为“远程客户端”继续进入，而不是直接崩溃退出。
2. **局域网 IP 获取**：Tauri 新增 `get_lan_ip` 命令，桌面端在设置页能直接显示本机局域网 IP，方便手机端填入。
3. **未连接提醒**：`ProblemList.vue` 增加网络错误捕获，无法连接服务器时顶部显示醒目黄色警告条，引导用户去设置。

### 五、移动端深度适配

1. **NavBar 溢出修复**：在移动端隐藏用户名与徽章，缩短品牌名，允许导航栏横向滑动，彻底解决 1440P 屏幕下撑爆页面的问题。
2. **双指缩放**：修改 `index.html` 的 `meta viewport`，并在 Android 原生 `MainActivity.java` 中强制开启 WebView 的 `setSupportZoom`。
3. **代码编辑器降级**：Monaco Editor 在手机输入法下严重卡顿。移动端切换为原生 `<textarea>`，并附带横向滑动的快捷符号工具栏（Tab, 括号, 分号等）。
4. **横屏代码模式**：引入 `@capacitor/screen-orientation`。点击按钮旋转手机屏幕，并应用 `focus-mode` CSS，隐藏左侧题目，编辑器铺满屏幕。

### 六、踩坑记录

#### 1、移动端 Monaco 输入卡死
**现象**：手机打字时吞字，甚至导致整个 App 无响应。
**原因**：Monaco 对 Android WebView 输入法兼容极差。
**解决**：移动端使用原生 `<textarea>` 加工具栏方案。

#### 2、桌面端横屏退出按钮消失
**现象**：桌面端点击横屏代码模式后，按钮消失。
**原因**：`focus-mode` CSS 误将整个 `.card-header` 隐藏了。
**解决**：在横屏 CSS 中单独保留头部区域，并只隐藏题目和辅助信息。

#### 3、首个用户注册未生效
**现象**：清空数据库后注册依然是普通用户。
**原因**：Docker 后端未重新编译，跑的还是旧代码。
**解决**：`docker compose build backend` 后重启。
